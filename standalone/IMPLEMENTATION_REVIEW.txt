1. ARCHITECTURE OVERVIEW
================================================================

The standalone implementation uses a HYBRID dependency management approach:
- VCPKG: For industrial-grade libraries (OpenCASCADE, libharu, Boost, etc.)
- SOURCE BUILD: For MeshLib-specific or customized thirdparty libraries

This approach ensures:
 Reproducible builds across platforms
 Version control and stability
 Minimal binary size for distribution
 Full industrial CAD/CAM format support
